# java-engineer-mentoring
Mentoring topics for people who wants to transition from other languages (or platforms like Video Games) to become Java Engineers

## Topics to Cover

- Java World 
- JPA World 
- A touch of Micro and Macro Design
- Design Patterns easy to apply in the real world
- Engineering Practices easy to embrace to boost productivity
- TDD
- Testing
